## 一篇文章的三种读法

**理解版**：从头读冲突场景，再看方案。遇到术语用基础回链补一处，读完后能画出主要状态就停。

**讲述版**：合上正文，用末尾的两三分钟主线解释“问题—方案—反例—取舍”。说到某个名字时，要能继续解释它存什么、何时改变、谁检查它。

**追问版**：展开文章中的关键反例，假设删掉一处保护或改变完成顺序，说明会发生什么，再找对应源码与测试入口。

面试稿不是逐字背诵稿。怎样补自己的经历、怎样写简历、哪些数字需要证据，见[面试准备页](../interview/README.md)。
