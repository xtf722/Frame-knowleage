# 从小例子读懂 Frame：自学课程

[知识库首页](../README.md) · [练习运行方法](../labs/beginner/README.md) · [随手查语法](syntax-desk.md)

如果你认识一些类名，但 `async`、回调、`State<T>` 这些写法本身也不熟，从这里开始。每课直接给出解释、练习和折叠答案，可以自己往下学，不需要每答一道题都等 AI 回复。

## 每课怎么读

1. 先看一个用户动作或小问题，确认这次只要弄懂什么。
2. 读短代码和逐句解释。代码标为“片段”时，先理解它在函数或 State 中的位置。
3. 遇到预测题，停十秒写下结果，再展开答案看原因。
4. 做一个很小的改动，用自己的话解释新结果；完成本课的停止点就进入下一课。

答错时回到答案指向的那一步，不必重新通读全书。已经会的课可以直接做最后一道改动题，通过后跳过正文。

## 不用重学所有已经理解的内容

可以用三道题确定入口，答案在对应课程中：

- 能解释“函数调用已开始，但调用方没有等待”？从 03 的最后练习检查，再看 04。
- 能解释“变量改变但不主动安排 build”？从 05 的练习检查，再看 06。
- 能解释“State 没销毁，参数却从 A 变 B”？从 07 的练习检查，再看 08。

会背一个方法名和能修改一段代码是不同的进度。课程不会因为你看过一页就自动标为掌握，也不要求按固定天数完成。

## 用 AI 的时候，按一课而不是一道题推进

可以直接使用这个请求：

> 带我学习 Frame 知识库第 08 课。先用一个小例子讲清本课，再给我三道逐渐变化的练习。把答案折叠起来，让我自己核对；只在我解释错或追问时停下来。一次只引入一个必要概念，不展开大型源码。

也可以把自己的解释发给 AI，让它只指出遗漏的条件。完整阅读与复习方式见 [复习计划](../review/plan.md)。

## 内容适用范围

课程示例是原创教学程序，不是产品源码。基础方法以每课官方文档为依据；模块导读沿用原专题记录的 2026-09-09 源码快照。进入当前项目时先按 [来源说明](../evidence/README.md) 核对，不从练习结果推定真实设备行为。
